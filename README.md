### 🎮 About the Project

This project is a polished implementation of the classic Tic Tac Toe game. It was developed as an educational portfolio piece focusing on **DOM manipulation**, **asynchronous programming**, and **Cloud Backend integration**. The application transitions from a simple local game to a global competitive platform where players face an automated CPU and compete for a spot on a persistent leaderboard.

### ✨ Features

* **Player vs CPU Mode:** Automated opponent logic for a seamless single-player experience.
* **Global Leaderboard:** Real-time Hall of Fame powered by **Firebase Firestore**.
* **Dynamic UI:** Modern glassmorphism design with responsive feedback and animations.
* **Game State Logic:** Automatic detection of win conditions, draws, and turn management.
* **Persistence:** Player records are stored in the cloud, allowing for cross-device competition.

### 🛠️ Technologies Used

* **Frontend:** Semantic HTML5, CSS3 (Flexbox & Grid).
* **Logic:** Vanilla JavaScript (ES6+).

* **Backend/Database:** Firebase Firestore (NoSQL).
* **Hosting:** GitHub Pages.

### 🚀 How to Run Locally

1. **Clone the repository:**
```bash
git clone https://github.com/your-username/tictactoe-webapp.git

```


2. **Navigate to the folder:**
```bash
cd tictactoe-webapp

```


3. **Firebase Setup:** * Create a project in the [Firebase Console](https://console.firebase.google.com/).
* Enable **Firestore Database** in Test Mode.
* Replace the `firebaseConfig` object in `script.js` with your own credentials.


4. **Launch:**
* Open `index.html` in your browser (using **Live Server** is recommended for full Firebase functionality).
