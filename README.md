### 🎮 About the Project

This project is a polished implementation of the classic Tic Tac Toe game. It has evolved into a global competitive platform where players face an **Intelligent CPU** and compete for a spot on a persistent leaderboard. The core focuses on providing a smooth user experience with real-time data persistence.

### ✨ Key Features

* **🧠 Medium Difficulty AI (Minimax Algorithm):** The CPU uses a hybrid Minimax logic. It plays perfectly **60% of the time** to challenge the player, while allowing a **40% margin of error** to keep the game beatable and fun.
* **🔥 Win Streak System:** Players who achieve 3 or more consecutive wins are highlighted with a **fire emoji** in the rankings. Be careful: losing a single match resets your streak instantly!
* **🏆 Global Leaderboard:** A real-time Hall of Fame powered by **Firebase Firestore**, showcasing the top players globally.
* **🌓 Dual Theme Support:** Includes a **Dark Mode** (default) and **Light Mode** toggle, with preferences saved in `localStorage`.
* **📱 Responsive & Animated UI:** Built with a modern aesthetic, featuring smooth transitions and "pop-in" animations for game moves.

### 🛠️ Technologies Used

* **Frontend:** Semantic HTML5, CSS3 (Custom Variables, Grid, Flexbox).
* **Logic:** Vanilla JavaScript (ES6+), recursive **Minimax Algorithm**.
* **Backend/Database:** Firebase Firestore (NoSQL).
* **Hosting:** Netlify / GitHub Pages.

### 🚀 How to Run Locally

1. **Clone the repository:**

```bash
git clone https://github.com/your-username/tictactoe-webapp.git

```

2. **Navigate to the folder:**

```bash
cd tictactoe-webapp

```

3. **Firebase Setup:**

* Create a project in the [Firebase Console](https://console.firebase.google.com/).
* Enable **Firestore Database**.
* Replace the `firebaseConfig` credentials in your `script.js`.

4. **Launch:**

* Open `index.html` in your browser.
